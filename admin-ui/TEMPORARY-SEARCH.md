# 공개 웹 검색 임시 목록

기존 `/admin`의 **SNS 계정 관리 → 새 계정 검색** 탭에서 사용합니다. 같은 카드의 **저장 후보**와 데이터·선택 상태를 분리하며 기존 지역·숫자 페이지·게시 기능을 보존합니다. 이 문서의 검증은 합성 응답 기준이며 실제 Brave 키 인증·운영 검색 성공을 의미하지 않습니다.

저장소에는 계정 검색용 공개 웹 검색 API가 없었고 기존 기능은 외부 Google 검색 창 열기뿐이었습니다. 새 서버나 새 유료 자원을 만들지 않고, 기존 서버에서 Brave Web Search API를 호출할 수 있도록 준비했습니다. 실제 검색 제공자의 결과는 키 없이 검증할 수 없으며 테스트 결과는 모두 합성 모의 응답입니다.

## 화면과 사용 흐름

1. `/admin`의 **SNS 계정 관리 → 새 계정 검색**에서 Instagram / Facebook / X / 네이버 블로그 중 하나, 키워드, 지역을 입력합니다. 지역은 기존 전국·시도·권역·시흥·영흥도·자유 입력을 재사용합니다.
2. 검색 서비스가 설정되지 않았으면 이유를 안내하고 검색을 차단합니다. 가짜 결과를 보여주거나 페이지 로드만으로 API를 호출하지 않습니다. 기존 외부 검색 열기와 수동 후보 관리는 그대로 사용할 수 있습니다.
3. 검색 버튼을 누를 때만 선택한 SNS 도메인으로 조회합니다. Instagram은 `instagram.com`, Facebook은 `facebook.com`, X는 `x.com` 또는 `twitter.com`, 네이버 블로그는 `blog.naver.com`입니다. 공개 웹 검색에 색인된 주소를 찾는 기능이며 SNS 내부 전체 계정 검색이나 SNS 로그인 기반 검색이 아닙니다.
4. 최대 20개를 한 번에 조회하고 화면은 10개씩 표시합니다. 같은 응답의 다음 10개 또는 이전에 본 페이지로 이동할 때는 추가 API 호출이 없습니다. 아직 조회하지 않은 **다음 결과 묶음 조회**는 새 API 요청입니다. 자동 미리 가져오기·자동 반복 검색·자동 재시도는 없습니다.
5. 체크박스와 **이 페이지 임시 전체 선택**은 현재 탭 메모리에서만 선택합니다. 프로필 주소와 게시물 주소를 구분하고 **지역 미검증**을 표시합니다. 원문 링크를 새 창으로 열어 사용자가 직접 확인합니다. URL 형식 판별은 계정 실존·소유자·지역·팔로우 검증이 아닙니다.
6. 영구 **추가**, 저장 후보로 전송, 내보내기, SNS 팔로우·맞팔·DM 버튼은 제공하지 않습니다. 기존 저장 후보 양식을 자동 채우지도 않습니다.
7. 카드 안의 **새 계정 검색 / 저장 후보** 전환은 결과·임시 체크·검색 입력과 저장 후보의 편집 초안을 유지합니다. 탭 전환은 새 API 요청이나 저장 후보 추가를 실행하지 않으며 15분 타이머를 다시 시작하지 않습니다. 새 검색, **임시 결과 지우기**, 새로고침, 페이지 떠나기 또는 첫 조회 후 15분 경과 시 임시 결과와 선택을 지웁니다. 숨겨진 검색 화면도 같은 수명 규칙을 적용합니다. 이미 저장한 수동 후보는 그대로 남으며 인증 만료 때도 임시 결과를 지웁니다.

서버가 한 번에 20개를 요청하더라도 실제 반환·표시 수는 더 적을 수 있습니다. 안전하지 않거나 지원하지 않는 URL 및 중복 URL은 생략합니다. 같은 URL의 추적 매개변수·모바일/데스크톱 별칭은 정규화합니다. 사용자명 주소와 숫자 ID가 같은 실제 계정인지까지는 알 수 없습니다.

Brave Web Search가 제공하는 `more_results_available`와 offset 0~9 제한을 따릅니다. 다음 페이지 정보가 누락되거나 null이면 추가 조회를 중지하며, 결과 전체가 없다고 단정하지 않습니다. 즉 최대 10번의 제공자 결과 묶음이며, 최대 20개의 화면 페이지가 될 수 있지만 전체 건수나 반환 개수는 보장하지 않습니다. 안전하게 표시 가능한 결과가 0개여도 제공자가 다음 결과를 알리면 사용자가 다음 묶음을 직접 조회할 수 있습니다. 마지막 제공자 묶음에서는 추가 호출을 차단합니다.

## 보관과 출처

[Brave Search API 이용약관](https://api-dashboard.search.brave.com/terms-of-service)의 2026-09-01판 3(b)(i)는 앱 운영에 필요한 일시 보관 예외를 명시합니다. 이 구현은 그 예외 범위에 맞추기 위해 페이지의 단기 열람·선택만 제공합니다. 결과의 DB·저널·localStorage·sessionStorage·파일·공유 캐시·애플리케이션 로그 저장 경로는 없습니다. 선택한 URL도 결과 일부이므로 같은 수명으로 지웁니다. 서버는 요청 처리 동안만 결과를 다루고 요청 사이에는 시간·횟수 제한 카운터만 유지합니다.

검색은 쿼리 문자열 없는 `POST /api/admin/temporary-search`로 보내며 키워드·지역은 JSON 본문에만 둡니다. 관리자 응답은 `Cache-Control: no-store`, `Pragma: no-cache`, `Expires: 0`입니다. 제공자 요청에는 공식 사양의 `Cache-Control: no-cache`를 사용하지만 제공자 측 처리는 best effort이므로 제공자 자체의 무보관을 보장하지 않습니다. 브라우저 저장소·Cache API를 사용하지 않고, `pagehide`에서 DOM과 메모리·입력을 지워 뒤로 가기 캐시로 결과가 되살아나는 것도 막습니다. 운영 프록시·APM에 요청/응답 본문 수집을 추가하지 않아야 합니다. 제공자 자신의 검색어 처리·보관은 제공자의 개인정보 조건을 따르므로 이 앱의 삭제 정책과 동일하다고 주장하지 않습니다.

원문 제목·짧은 설명·직접 출처 URL만 텍스트로 표시합니다. 검색 결과의 이미지·아이콘·썸네일을 내려받지 않습니다. 약관 4(d)의 `POWERED BY BRAVE` 및 로고를 포함하는 선택적 홍보용 브랜드 배지는 사용하지 않았습니다. 화면에는 검색 제공자에 대한 사실 안내, 이용조건 링크와 결과별 원문 출처 링크를 둡니다. 제휴·후원·검증을 표시하지 않습니다. 실제 운영 활성화 전에는 적용 계약·주문 조건 및 내부 관리자 이용조건 수락·검색어 전송/개인정보 고지 요건을 확인해야 합니다. 이번 개발안은 계약 체결이나 저장 권한 취득을 대신하지 않습니다.

영구 저장 기능을 나중에 검토하려면 사용자 승인뿐 아니라 당시 적용되는 제공자 계약의 저장 권한도 확인해야 합니다. 이번 임시 선택을 영구 후보 추가로 해석하면 안 됩니다.

## 서버 연결 준비와 제한

아래는 기존 서버 설정에 사용하는 이름입니다. 카드 통합 작업에서 실제 값을 조회·출력·변경하지 않았습니다.

| 서버 환경변수 | 의미 |
|---|---|
| `BRAVE_SEARCH_API_KEY` | 서버 전용 Brave API 자격증명. 브라우저·Git·로그에 노출하지 않음 |
| `BRAVE_SEARCH_ENABLED` | 명시적으로 `true`일 때만 사용 가능. 기본은 비활성 |

입력 위치는 기존 Render 서비스 `srv-d81bo0rtqb8s738pcv6g`의 [Environment 화면](https://dashboard.render.com/web/srv-d81bo0rtqb8s738pcv6g/env)입니다. 사용자가 키를 직접 입력하며 채팅으로 전달하지 않습니다. 저장 옵션에 따라 재배포가 실행될 수 있으므로 실제 설정·활성화·배포는 별도 단계입니다.

둘 다 필요합니다. 설정 존재만으로 연결 성공이나 과금 가능 여부를 검증했다고 표시하지 않습니다. 현재 요금·선불 크레딧·자동충전·계정 활성화 조건은 별도 비용 조사와 제공자 대시보드 확인 대상입니다. 이 코드의 요청 제한은 결제 금액 상한이 아닙니다. 키만 입력하거나 페이지를 여는 것으로 검색하지 않습니다.

- 기존 관리자 세션·동일 Origin·CSRF를 재사용합니다. GET, 쿼리 매개변수가 있는 검색 POST, 임의 필드나 목적지 URL을 받지 않습니다.
- 입력은 키워드 1~200자, 지역 0~100자, 고정 SNS 식별자, 정수 제공자 페이지 0~9만 허용합니다. 최종 제공자 검색어는 400자·50단어 이내입니다.
- 요청 대상은 고정 `https://api.search.brave.com/res/v1/web/search` 하나입니다. 입력/검색 결과 URL로 네트워크 요청하지 않습니다. 반환된 SNS 페이지를 스크래핑하거나 비공개 API를 사용하지 않습니다.
- 타임아웃 8초, 응답 상한 1MiB, 리다이렉트 0회, 자동 재시도 0회입니다. 응답은 web 결과만 사용하고 반환 필드를 제한합니다.
- 모든 관리자 세션을 합쳐 동시 1개, 2초 간격, 분당 최대 20개 요청입니다. 실패한 실제 요청도 횟수에 포함합니다. 제공자 429는 60초 제한과 `Retry-After`를 전달합니다. 카운터는 서버 프로세스 메모리만 사용하므로 재시작 시 초기화되며 요금 상한을 보장하지 않습니다.
- 제공자 인증/권한, 사용량/결제, 요청 제한, 시간 초과, 네트워크/응답 오류는 고정 오류 코드로만 전달합니다. 원문 오류·키·요청 URL·응답 결과를 로그에 남기지 않습니다.
- 공식 SNS HTTPS 호스트·지원하는 프로필/게시물 경로만 허용합니다. 자격증명·임의 포트·다른 호스트·단축/리다이렉트·로그인·비공개 경로는 제외합니다. 링크는 `noopener noreferrer`로 새 창에서 열며 외부 이미지를 자동 로드하지 않습니다.

## 구현 파일

| 파일 | 용도 |
|---|---|
| `backend/temporary-search.cjs` | 고정 Brave API 어댑터, 입력/응답 검증, 요청 제한, 오류 분류 |
| `backend/service.cjs`, `server-core.cjs` | 기존 인증 API 및 인증된 설정 상태에 연결 |
| `public/search-result-url.js` | 서버·브라우저가 공유하는 SNS URL 안전 검사·정규화·프로필/게시물 구분 |
| `public/temporary-search.js`, `public/temporary-search.css` | 페이지 메모리 수명, 임시 선택, 10개 페이지, 조회/삭제·오류 표시 |
| `public/admin.html`, `public/app.js` | 기존 관리자 안의 독립 임시 검색 영역 |
| `tests/temporary-search.test.mjs` | 보안·공급자 오류·0건·SNS·페이지·요청 제한·DB 보존 검사 |
| `scripts/temporary-search-browser-test.mjs` | 합성 API 응답을 이용한 전체 사용 흐름·모바일·메모리 삭제·기존 후보 보존 검사 |

## 실행과 검증

```bash
npm run admin:check
npm run admin:test
CHROMIUM_EXECUTABLE=/usr/bin/chromium node admin-ui/scripts/temporary-search-browser-test.mjs
```

Playwright 모듈은 필요하면 `PLAYWRIGHT_MODULE`로 지정합니다. 새 런타임 의존성은 추가하지 않았습니다. 브라우저 검사는 별도 임시 저장소·일회성 합성 관리자·합성 키·모의 제공자 응답만 사용합니다. 테스트 캡처에 보이는 합성 URL/설명은 실제 검색 결과가 아닙니다. 원문 링크 열기도 로컬 대체 응답으로 처리합니다.

임시 검색 단위·HTTP 검사 10개, 기존 저장 후보·페이지·지역 및 링크 소개 브라우저 회귀를 사용합니다. 임시 검색 브라우저는 카드·탭·키보드·데이터 분리를 포함한 11개 흐름입니다. 결과와 합성 화면은 `test-results/temporary-search/`에 생성됩니다. 이 폴더는 기존 정책에 따라 커밋하지 않습니다. 실제 Brave API 인증·결과 품질·SNS별 색인 범위·실제 응답 형식·운영 네트워크는 모의 검사로 검증할 수 없습니다.

배포 상태와 테스트 실행 결과는 각 작업의 배포 보고서를 확인하세요. 실제 키 인증과 검색 결과는 사용자가 직접 검색한 뒤 별도로 확인해야 합니다.

공식 사양: [Web Search](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started), [Web Search API reference](https://api-dashboard.search.brave.com/api-reference/web/search/get), [API 이용약관](https://api-dashboard.search.brave.com/terms-of-service).
