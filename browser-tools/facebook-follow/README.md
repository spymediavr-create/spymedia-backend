# SpyMedia Facebook 선택 팔로우 도구 0.1.0

기존 SNS 관리자의 Facebook 검색 결과 또는 저장 후보에서 직접 선택하고 확인한 프로필만 처리하는 Chrome/Edge 확장입니다. Instagram 확장과 별도로 설치하며 Instagram 권한·토큰·기존 확장은 변경하지 않습니다.

## 설치와 실행

1. SNS 관리자에서 **Facebook 도구 0.1.0 받기**를 눌러 압축을 내려받습니다.
2. 압축을 푼 뒤 Chrome/Edge 확장 프로그램 관리에서 개발자 모드를 켜고 **압축 해제된 확장 프로그램 로드**로 이 폴더를 선택합니다. Facebook과 SNS 관리자 사이트 접근 권한은 사용자가 직접 검토하고 허용합니다.
3. 같은 브라우저 프로필에서 SNS 관리자와 Facebook에 로그인합니다. Facebook에서는 **스파이미디어 페이지**로 전환합니다. 개인 계정으로 페이지를 관리할 수 있는 것과 스파이미디어 페이지로 활동하는 것은 다릅니다.
4. 관리자에서 Facebook 프로필 1~10개를 선택합니다. 실행 계정과 대상을 확인하고 시작하면 뒤에 열린 Facebook 탭 하나에서 순서대로 처리합니다.

실행 계정은 스파이미디어 페이지 `61594869881531`로 고정됩니다. 대상별로 먼저 Facebook `/me/`를 열어 현재 프로필의 ID·이름과 본인 페이지 표시를 확인하고, 대상 프로필에서도 전역 Facebook 탐색 영역의 광고 센터 링크에 표시된 활동 페이지 ID를 다시 확인합니다. 개인 계정 또는 필요한 증거가 없는 화면에서는 중지합니다. 계정 전환·로그인·인증정보 갱신은 자동 실행하지 않습니다.

현재 화면이 팔로우 기능을 제공하지 않거나 계정·대상·팔로우 버튼이 명확하지 않으면 중지합니다. 팔로우 버튼이 보이지 않는 상황에서 ‘좋아요’나 ‘친구 추가’를 대신 누르지 않습니다. 추천 계정·피드의 다른 버튼을 대상 버튼으로 사용하지 않습니다.

## 실행과 결과

- 이미 팔로잉인 대상은 다시 클릭하지 않습니다.
- 한 대상의 팔로우 버튼은 최대 한 번만 클릭합니다. 이후 최대 8초 동안 상태를 읽어 확인하며 팔로우 완료·기존 팔로잉·결과 확인 필요를 구분합니다. 친구 요청과 승인 대기를 팔로우 완료로 취급하지 않습니다.
- 로그인 만료, 다른 활동 프로필, 추가 인증, 활동 제한, 불명확한 결과는 전체 작업을 중지합니다. 자동 재클릭·자동 재시도·자동 재개·언팔로우 기능은 없습니다.
- 작업 중지, 관리자 이탈, 선택 변경, 관리자 인증 만료는 남은 작업을 취소합니다. 이미 완료된 팔로우는 취소되지 않습니다.
- 진행 중에는 열린 Facebook 작업 탭을 직접 조작하지 마세요. 중단된 대상의 상태는 Facebook에서 확인한 뒤 다음 작업을 준비합니다.

선택 목록·진행 상태는 메모리에만 존재하며 최대 15분 뒤 만료됩니다. 확장 서비스워커나 브라우저가 재시작되면 복구하거나 자동 재개하지 않습니다. 브라우저의 방문 기록과 Facebook 측 접속 기록은 남을 수 있습니다.

공식 게시 API나 게시 토큰을 사용하는 기능이 아닙니다. Facebook 웹 화면의 변경이나 계정 제한으로 중지될 수 있으며 제한을 우회하지 않습니다. 합성 화면·모의 응답 테스트는 실제 Facebook 팔로우 성공을 의미하지 않습니다. 실제 대상의 실행은 사용자가 설치 및 계정·대상을 확인한 뒤 별도로 검증해야 합니다.

## 개발

`node admin-ui/scripts/package-facebook-follow-extension.mjs`로 인증 다운로드용 ZIP을 만듭니다. 빌드 과정에 원격 코드나 추가 의존성이 없습니다. Instagram ZIP과 패키징 스크립트는 변경하지 않습니다.

관리자 메시지는 `spymedia-admin-facebook-follow`, 응답은 `spymedia-facebook-follow-extension` source를 사용합니다. 작업은 동일한 최상위 관리자 탭에 묶이며 PREPARE → START → STEP 순서, 실행 계정·대상 목록·만료 시각·결과 인덱스를 확인합니다. 한 번에 한 작업만 허용하고 START/STEP 중복 호출은 거절합니다. 인증정보·검색어·검색 설명·비공개 API는 확장에 전달하지 않습니다.
