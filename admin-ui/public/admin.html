공개 웹 검색 · 임시 열람

결과와 체크는 현재 페이지의 임시 선택이며 저장 후보에 추가되지 않습니다. 두 화면 탭을 바꿔도 유지되지만, 새 검색·새로고침·페이지 떠나기·첫 조회 후 15분 경과·로그인 만료 시 지워집니다.

선택한 SNS의 공개 웹 검색에 등록된 일부 주소입니다. 지역·계정 실존·팔로우 상태는 미검증이며 프로필·게시물 구분은 URL 형식에 따른 안내입니다. 원문에서 직접 확인하세요.

임시 검색 조건

검색어와 지역은 Brave 검색 API에 전달됩니다. 검색·새 결과 묶음 조회에는 API 요금제에 따른 비용이 발생할 수 있습니다. 자동 검색·재시도는 하지 않습니다. 검색 API 이용조건

검색 서비스 설정을 확인하고 있습니다.

직접 조사한 계정의 저장 목록

프로필 주소를 직접 추가하고 검토할 후보를 체크하세요. 이 화면의 체크·메모·처리 상태는 관리자에 저장되며 탭 전환·새로고침 후에도 남습니다.

‘팔로우 완료 (수동 기록)’는 사용자가 SNS에서 직접 처리한 뒤 남기는 기록입니다. 실제 팔로우 여부를 자동 확인하지 않습니다.

서버 연결 상태를 확인하고 있습니다.

다시 로그인
후보 추가

선택한 SNS의 HTTPS 프로필 주소만 받습니다. Facebook은 사용자명·숫자 ID·profile.php?id= 주소, 네이버는 블로그 홈 주소를 사용하세요.

저장 후보 검색은 계정/기관·업체명·업종·지역·추천 이유·메모·프로필 주소에서 찾습니다. 업종 필터는 일치, 지역은 전국·권역·시도 약칭과 자유 입력을 지원하고, 키워드는 포함 검색입니다.

전국 또는 빈 지역은 지역 제한 없이 검색합니다. 권역은 명시된 시도·권역명과 기존 시흥·영흥도를 기준으로 찾으며, 지역 미입력 후보의 위치는 추정하지 않습니다.

새 계정 조사: 외부 검색 열기 ↗먼저 검색어를 입력하세요. Google을 새 창에서 엽니다. 검색 결과는 관리자에 수집·저장되지 않으며, 확인한 프로필 주소를 직접 추가하세요.
