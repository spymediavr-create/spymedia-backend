# SNS 팔로우 도구

기존 `/admin`의 SNS 계정 관리에 연결합니다. 사진·릴스 게시, X·Facebook 링크 소개, 블로그 원고 기능과 별개입니다. API 인증정보나 게시 권한을 자동 변경하지 않습니다.

## Instagram

검색 조건으로 조회한 뒤 **프로필 주소만 1~10개 체크 → 선택한 Instagram 계정 팔로우 → 관리자 안의 계정·대상 목록 확인 → 확인한 Instagram 계정 팔로우 시작**을 사용합니다. 직접 등록한 저장 후보의 현재 페이지 선택도 같은 방식으로 실행할 수 있습니다. 게시물 주소를 프로필로 추측하지 않습니다. 선택하거나 검토 목록을 여는 것만으로는 확장 작업을 시작하지 않습니다.

실행에는 별도 Chrome/Edge 확장 **0.2.1 이상**이 필요합니다. 관리자의 **Instagram 도구 0.2.1 받기**에서 인증된 ZIP을 내려받아 압축을 풀고 확장 프로그램 관리에서 개발자 모드의 '압축 해제된 확장 프로그램 로드'로 설치합니다. 기존 설치는 파일 교체 후 확장 프로그램 새로고침과 관리자 새로고침이 필요합니다. 구버전은 실행 전 버전 확인에서 차단하고 업데이트 방법을 표시합니다. 사용자 브라우저에서 확장의 권한을 직접 검토·허용해야 합니다. 같은 브라우저 프로필에서 관리자와 Instagram에 로그인합니다. Codex 내장 브라우저와 Chrome의 로그인은 서로 공유되지 않습니다.

관리자 안에서 대상과 실행 계정 `spymedia_kr`를 확인하고 시작합니다. 관리자 화면의 초점을 유지하며 뒤에 열린 Instagram 탭 하나를 순서대로 이동하고 도구가 팔로우 버튼을 한 번 누른 뒤 결과를 확인합니다. 사용자는 진행 중에 해당 탭의 팔로우 버튼을 직접 누르지 않습니다. 별도 확장 검토 창은 새 관리자 흐름에서 열지 않습니다. 이미 팔로잉/요청 중이면 다시 누르지 않습니다. 로그인 계정 불일치, 추가 인증, 제한, 화면 구조 불일치, 결과 불확실 시 중단합니다. 캡차·제한 우회, 비공개 API, 자동 로그인, 재시도, 언팔로우, 맞팔 유도 반복은 제공하지 않습니다. 중단은 이미 완료된 팔로우를 취소하지 않습니다.

0.2.1은 클릭 후 화면 갱신 중에 버튼이 잠시 사라져도 최대 8초 동안 결과를 읽어 확인합니다. 팔로우 버튼을 재클릭하지 않으며, 계속 불명확하면 ‘결과 확인 필요’로 중지합니다. 이미 ‘팔로잉’인 대상은 건너뜁니다.

공식 Instagram API 연동이 아닌 화면 자동화입니다. 모의 테스트 통과만으로 실제 Instagram 화면에서의 동작·안정성이나 플랫폼 승인을 입증하지 않습니다. 공식 게시 권한과 별개이며 플랫폼 제한 가능성이 있습니다. 실제 동작은 설치와 사용자가 승인한 대상 검토 후 확인해야 합니다.

검색 결과·선택·확장 작업은 메모리에서만 보관합니다. 검색 결과의 첫 조회 후 15분을 넘겨 실행하지 않고 관리자 화면 떠나기·로그인 만료·선택 변경·결과 삭제는 중단을 요청하며 오래된 검토 목록을 지웁니다. 완료·요청 전송·기존 팔로잉·중지 사유는 관리자에 표시하며 후보의 '수동 완료' 상태를 자동 조작하지 않습니다. 확장 응답의 실행 계정·대상 전체 목록·만료 시각·진행 순서가 일치하지 않거나 한 단계 응답이 45초를 넘으면 중단하고 재전송하지 않습니다. 실제 프로필 방문은 브라우저 자체 방문 기록과 Instagram 측 기록에 남을 수 있습니다. 확장 또는 브라우저가 재시작되면 자동 재개하지 않습니다.

확장 소스는 `browser-tools/instagram-follow/`입니다. 수정 후 `node admin-ui/scripts/package-follow-extension.mjs`를 실행해 배포 ZIP을 갱신합니다. ZIP 경로는 고정이며 로그인 없이 내려받을 수 없습니다.

## X

검색 결과나 저장 후보에서 프로필 **1개**를 선택하고 계정 확인을 누릅니다. 공식 API로 실행 계정 `spymedia_kor` 및 대상 ID/사용자명을 확인한 뒤, 별도 실행 버튼과 확인창에서 동의한 한 건만 전송합니다. 준비 조회도 API 이용료가 발생할 수 있습니다. '팔로워를 늘려 주는 기능'이 아니라 내 계정이 상대를 팔로우하는 기능입니다.

새 `X_FOLLOW_ENABLED` 설정은 기본 비활성입니다. 기존 인증·저장소와 `X_COST_LIMIT_ACKNOWLEDGED`도 필요합니다. 실제 운영 설정 활성화·새 권한·새 토큰·비용 변경은 사용자 승인 후에만 진행합니다. X 게시 설정을 자동 변경하지 않습니다. OAuth 1.0a 사용자 인증 또는 OAuth 2.0의 `tweet.read users.read follows.write`가 필요하며 조회 성공만으로 팔로우 권한을 검증했다고 표시하지 않습니다.

X의 규칙은 대량·공격적·무차별 팔로우를 금지하므로 선택한 목록을 자동 반복하지 않습니다. 실제 API 응답에서 완료와 승인 대기 상태를 구분하고, 전송 직전 기록 및 중복 검사를 통해 재시작·이중 클릭 후 POST를 자동 반복하지 않습니다. 원문 검색 정보는 저널에 저장하지 않습니다. 상세 설계는 `X-FOLLOW.md`를 참고하세요.

## 네이버 블로그 조사

공개 API에서 블로그 검색은 지원하지만 이웃추가·서로이웃 신청 API는 확인되지 않았습니다. 서로이웃은 상대 동의가 필요합니다. 이번 변경은 네이버 자동 이웃추가를 구현하지 않습니다. 기존 검색·원문 프로필 열기·블로그 원고 기능을 유지합니다.

## 검증 범위

단위·HTTP·브라우저 테스트는 합성 대상과 모의 외부 응답을 사용합니다. 실제 팔로우, 게시, 토큰 갱신, 크레딧 구매는 테스트에서 실행하지 않습니다. 배포 여부와 실제 플랫폼에서 확인한 항목은 작업 완료 보고를 별도로 확인하세요.
