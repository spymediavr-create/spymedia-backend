# SpyMedia 네이버 선택 이웃추가 0.1.0

기존 SNS 관리자에서 검토한 블로그 1~10개를 `spymedia` 블로그의 **기존 광고 그룹에 일반 이웃**으로 추가하는 별도 Chrome/Edge 확장 도구입니다. Instagram·Facebook 도구 및 기존 게시 코드를 변경하지 않습니다. 서로이웃 신청이나 신청 메시지는 보내지 않습니다.

## 설치와 실행

1. SNS 관리자에 로그인한 뒤 **네이버 이웃추가 도구 0.1.0 받기**에서 ZIP을 다운로드하고 새 폴더에 압축을 풉니다.
2. Chrome/Edge의 확장 프로그램 관리에서 개발자 모드를 켜고 **압축 해제된 확장 프로그램 로드**로 해당 폴더를 선택합니다. `blog.naver.com`, SNS 관리자 주소 및 스크립트 실행 권한은 설치 화면에서 사용자가 검토하고 직접 허용합니다.
3. 같은 브라우저 프로필에서 SNS 관리자와 네이버에 로그인하고, 내 블로그가 `https://blog.naver.com/spymedia`인지 확인합니다. 다른 브라우저의 로그인 세션은 공유되지 않습니다.
4. `spymedia` 블로그의 기존 이웃 그룹에 이름이 정확히 **광고**인 그룹이 하나 있는지 확인합니다. 도구는 새 그룹을 만들거나 다른 그룹으로 대신 추가하지 않습니다.
5. 관리자에서 네이버 블로그 대상을 선택하고 실행 블로그·광고 그룹·대상 목록을 검토한 뒤 **확인한 블로그 이웃추가 시작**을 누릅니다. 선택하거나 검토 목록을 여는 것만으로 이웃추가하지 않습니다.

실행 시 도구는 이웃추가 팝업의 **이웃 → 다음 → 광고 그룹 선택 → 다음** 순서를 처리합니다. 완료 문구 또는 대상 블로그의 이웃 상태를 확인한 뒤 관리자에 결과를 표시합니다. 광고 그룹이 없거나 같은 이름의 그룹을 하나로 구분할 수 없으면 해당 대상에서 중지합니다.

게시글 검색 결과를 선택한 경우 관리자가 해당 게시글 URL의 블로그 ID를 식별하여 대상 블로그를 검토 목록에 명시할 수 있습니다. 확장 도구는 검토가 끝난 정확한 블로그 프로필 주소만 받습니다.

## 동작 범위

- 실행 블로그는 `spymedia`로 고정됩니다. 블로그 ID는 네이버 로그인 ID나 닉네임과 동일하다고 가정하지 않습니다.
- 이웃 그룹은 기존 **광고** 그룹으로 고정됩니다. `group_missing`은 해당 그룹이 없는 경우, `group_ambiguous`는 한 그룹으로 확인하지 못한 경우입니다. 두 경우 모두 다른 그룹 선택이나 그룹 생성 없이 중지합니다.
- 정상 이웃 상태가 확인되면 완료 또는 기존 이웃으로 표시합니다. 이미 이웃이면 추가 버튼을 다시 누르지 않습니다.
- 대상별 계정·블로그·일반 이웃 폼을 확인한 뒤 전송은 한 번만 실행합니다. 결과 확인은 읽기만 반복하며 전송을 재시도하지 않습니다.
- 로그인 필요, 계정 불일치, 추가 인증·캡차·활동 제한, 예상하지 못한 화면, 불확실한 결과가 나오면 중지합니다. 로그인·보안 절차를 자동 처리하거나 우회하지 않습니다.
- 네이버 API 토큰, 쿠키, 비밀번호, 숨은 앱 상태 또는 비공개 API를 읽거나 사용하지 않습니다. 새 유료 서비스나 서버 작업 프로세스도 필요하지 않습니다.
- 선택 목록과 진행 상태는 확장 메모리에만 최대 15분 유지됩니다. 관리자 이동·닫기·로그인 만료·선택 변경은 중단을 요청하며, 브라우저/확장 재시작 후 자동 재개하지 않습니다. 중지해도 이미 추가된 이웃은 삭제하지 않습니다.
- 관리자와 네이버 사이의 연결을 처리하는 기능입니다. 네이버 공식 이웃 API 또는 플랫폼 승인 도구라고 표시하지 않습니다.

실제 네이버 화면 동작 확인과 모의 테스트 결과는 구분합니다. 모의 테스트만으로 실제 이웃추가 성공을 보장하지 않으며, 실제 실행은 설치 후 관리자에서 검토하고 승인한 대상에 대해서만 진행합니다.

## 개발

소스는 `browser-tools/naver-neighbor/`입니다. `node admin-ui/scripts/package-naver-neighbor-extension.mjs`로 고정된 파일 목록만 ZIP에 포함합니다. `admin-ui/downloads/naver-neighbor.zip`은 인증된 관리자 다운로드로 제공합니다.
