# SNS 팔로우 도구

기존 `/admin`의 SNS 계정 관리에 연결합니다. 사진·릴스 게시, X·Facebook 링크 소개, 블로그 원고 기능과 별개입니다. API 인증정보나 게시 권한을 자동 변경하지 않습니다.

## Instagram

검색 조건으로 조회한 뒤 **프로필 주소만 1~10개 체크 → 선택한 Instagram 계정 팔로우 → 관리자 안의 계정·대상 목록 확인 → 확인한 Instagram 계정 팔로우 시작**을 사용합니다. 직접 등록한 저장 후보의 현재 페이지 선택도 같은 방식으로 실행할 수 있습니다. 게시물 주소를 프로필로 추측하지 않습니다. 선택하거나 검토 목록을 여는 것만으로는 확장 작업을 시작하지 않습니다.

실행에는 별도 Chrome/Edge 확장 **0.2.2 이상**이 필요합니다. 관리자의 **Instagram 도구 0.2.2 받기**에서 인증된 ZIP을 내려받아 압축을 풀고 확장 프로그램 관리에서 개발자 모드의 '압축 해제된 확장 프로그램 로드'로 설치합니다. 기존 설치는 파일 교체 후 확장 프로그램 새로고침과 관리자 새로고침이 필요합니다. 구버전은 실행 전 버전 확인에서 차단하고 업데이트 방법을 표시합니다. 사용자 브라우저에서 확장의 권한을 직접 검토·허용해야 합니다. 같은 브라우저 프로필에서 관리자와 Instagram에 로그인합니다. Codex 내장 브라우저와 Chrome의 로그인은 서로 공유되지 않습니다.

관리자 안에서 대상과 실행 계정 `spymedia_kr`를 확인하고 시작합니다. 관리자 화면의 초점을 유지하며 뒤에 열린 Instagram 탭 하나를 순서대로 이동하고 도구가 팔로우 버튼을 한 번 누른 뒤 결과를 확인합니다. 사용자는 진행 중에 해당 탭의 팔로우 버튼을 직접 누르지 않습니다. 별도 확장 검토 창은 새 관리자 흐름에서 열지 않습니다. 이미 팔로잉/요청 중이면 다시 누르지 않습니다. 로그인 계정 불일치, 추가 인증, 제한, 화면 구조 불일치, 결과 불확실 시 중단합니다. 캡차·제한 우회, 비공개 API, 자동 로그인, 재시도, 언팔로우, 맞팔 유도 반복은 제공하지 않습니다. 중단은 이미 완료된 팔로우를 취소하지 않습니다.

0.2.2는 대상 프로필 아래에 나타나는 추천 계정 목록의 버튼을 결과 판별에서 제외합니다. 대상의 ‘팔로잉’과 추천 계정의 ‘팔로우’를 함께 세어 결과 확인 필요로 표시하던 문제를 수정했습니다. 클릭 후 화면 갱신 중에 버튼이 잠시 사라져도 최대 8초 동안 결과를 읽어 확인합니다. 팔로우 버튼을 재클릭하지 않으며, 계속 불명확하면 ‘결과 확인 필요’로 중지합니다. 이미 ‘팔로잉’인 대상은 건너뜁니다.

### 다음 검색에서 팔로잉 계정 제외

관리자가 검증한 `followed`, `following`, `request_sent`, `requested` 결과마다 기존 서버 저장소에 실행 계정 `spymedia_kr`의 계정명·관계 상태·확인 시각만 기록합니다. 다음 Instagram 검색에서 해당 프로필은 제외하고 제외 개수를 표시합니다. 실패·미확인 결과는 기록하지 않습니다. 서버 재시작이나 관리자 재로그인 후에도 제외 기록은 유지됩니다. 원본 검색어·검색 설명·검색 결과 목록은 계속 임시 메모리에만 보관합니다.

검색은 기존 제공자 결과 묶음을 한 번만 조회하며, 제외한 수만큼 결과를 채우기 위해 추가 요청을 자동 실행하지 않습니다. 게시물 URL에서 계정을 추측하지 않고, X·Facebook·블로그 결과에는 이 Instagram 기록을 적용하지 않습니다. Instagram 전체 팔로잉 목록을 자동 수집하거나 실제 관계 상태를 매 검색마다 조회하는 기능은 아닙니다.

이 기능을 적용하기 전에 완료했거나 Instagram에서 직접 팔로우한 계정은 **Instagram 검색 제외 계정 관리**에서 기존 팔로잉 계정명으로 등록할 수 있습니다. 잘못 등록했거나 팔로우를 해제한 경우 **검색에 다시 표시**로 제외 기록만 제거합니다. 이 버튼은 Instagram 팔로우 상태를 변경하지 않습니다. 제외 기록 저장 실패는 실제 팔로우 실패와 구분해 안내하며, 인증 만료 시에는 남은 팔로우 작업을 중지합니다.

기존 확장 도구 0.2.2를 그대로 사용합니다. 검색 제외 기능 때문에 확장을 다시 설치할 필요는 없습니다.

공식 Instagram API 연동이 아닌 화면 자동화입니다. 모의 테스트 통과만으로 실제 Instagram 화면에서의 동작·안정성이나 플랫폼 승인을 입증하지 않습니다. 공식 게시 권한과 별개이며 플랫폼 제한 가능성이 있습니다. 실제 동작은 설치와 사용자가 승인한 대상 검토 후 확인해야 합니다.

검색 결과·선택·확장 작업은 메모리에서만 보관합니다. 검색 결과의 첫 조회 후 15분을 넘겨 실행하지 않고 관리자 화면 떠나기·로그인 만료·선택 변경·결과 삭제는 중단을 요청하며 오래된 검토 목록을 지웁니다. 완료·요청 전송·기존 팔로잉·중지 사유는 관리자에 표시하며 후보의 '수동 완료' 상태를 자동 조작하지 않습니다. 확장 응답의 실행 계정·대상 전체 목록·만료 시각·진행 순서가 일치하지 않거나 한 단계 응답이 45초를 넘으면 중단하고 재전송하지 않습니다. 실제 프로필 방문은 브라우저 자체 방문 기록과 Instagram 측 기록에 남을 수 있습니다. 확장 또는 브라우저가 재시작되면 자동 재개하지 않습니다.

확장 소스는 `browser-tools/instagram-follow/`입니다. 수정 후 `node admin-ui/scripts/package-follow-extension.mjs`를 실행해 배포 ZIP을 갱신합니다. ZIP 경로는 고정이며 로그인 없이 내려받을 수 없습니다.

## Facebook

SNS 계정 관리의 Facebook 검색 결과 또는 저장 후보에서 **프로필 주소 1~10개 선택 → 선택한 Facebook 계정 팔로우 → 실행 페이지와 목록 검토 → 확인한 Facebook 계정 팔로우 시작**으로 실행합니다. 검토 목록을 여는 것만으로는 팔로우하지 않습니다. 기존 Instagram·X·블로그 기능과 게시 코드는 유지합니다.

별도 Chrome/Edge 확장 **Facebook 도구 0.1.0**을 관리자의 인증된 다운로드에서 받아 설치해야 합니다. Instagram 확장의 권한은 바꾸지 않습니다. 새 도구는 `https://www.facebook.com/*` 및 이 SNS 관리자 주소에 접근하고 `scripting`을 사용하므로, 사용자가 설치 화면에서 해당 권한을 검토하고 직접 허용합니다. 토큰·Facebook API 권한·Render 환경 변수 변경이나 새 유료 서비스는 없습니다.

같은 브라우저 프로필에서 Facebook에 로그인하고 **스파이미디어 페이지(61594869881531)**로 전환합니다. 개인 프로필에서 페이지를 보고 있는 것과 페이지로 활동하는 것은 다릅니다. 도구는 대상마다 `/me/`의 실제 페이지 주소·이름·프로필 편집 링크와 전역 Facebook 탐색 메뉴의 페이지별 광고 센터 ID를 확인합니다. 대상 페이지에서도 전역 메뉴의 실행 페이지 ID를 다시 읽습니다. 페이지 관리 사이드바나 이름만으로 실행 계정을 추측하지 않습니다.

검증된 대상 프로필의 팔로워·팔로잉 링크와 인접한 **팔로우/Follow** 버튼만 한 번 클릭하고, **팔로잉/Following** 표시로 결과를 확인합니다. 이미 팔로잉이면 건너뜁니다. 친구 추가·친구 요청·게시물 좋아요·추천 계정 버튼은 처리하지 않습니다. 로그인·다른 실행 계정·추가 인증·활동 제한·지원하지 않는 화면·불확실한 결과에서는 중지하며 자동 재클릭하지 않습니다. 선택한 프로필 주소가 다른 별칭으로 리다이렉트되어 같은 계정임을 화면에서 확인하지 못하면 중지할 수 있습니다.

이 도구는 공식 팔로우 생성 API가 아니라 사용자 브라우저의 화면 자동화입니다. 좁은 화면 등에서 실행 페이지의 전역 메뉴 정보가 없거나 한국어·영어가 아닌 버튼은 지원하지 않습니다. 작업은 15분 동안 메모리에만 보관하고, 관리자 이탈·인증 만료·선택 변경·중지·도구 재시작 시 자동 재개하지 않습니다. 한 단계 응답 제한은 페이지 확인·이동을 포함해 90초입니다. 취소는 완료된 팔로우를 되돌리지 않습니다.

### 다음 검색에서 팔로잉 계정 제외

관리자에서 검증한 `followed`(팔로우 완료)·`following`(이미 팔로잉) 결과마다 스파이미디어 페이지 `61594869881531`의 검색 제외 기록을 저장합니다. 기록은 정규화한 프로필 주소·팔로잉 상태·확인 시각만 포함하며, 다음 Facebook 검색에서 해당 프로필을 제외하고 제외 개수를 표시합니다. 서버 재시작·관리자 재로그인 후에도 유지됩니다. 실패·결과 미확인·친구 요청은 제외하지 않으며, Instagram·X·블로그에는 Facebook 기록을 적용하지 않습니다.

검색 제공자는 기존과 같이 한 번만 조회합니다. 제외된 수를 채우기 위한 추가 검색은 하지 않습니다. 숫자 ID 주소와 `/people/이름/ID`는 같은 주소로 정규화하고, 프로필 별칭의 대소문자를 통일합니다. 같은 계정의 별칭 주소와 숫자 ID 주소를 연결하는 정보가 없으면 서로 다른 주소로 취급합니다. 게시물 주소를 프로필로 추측하거나 Facebook의 전체 관계 상태를 매 검색마다 수집하지 않습니다.

기능 적용 전에 완료한 계정이나 Facebook에서 직접 팔로우한 계정은 **Facebook 검색 제외 계정 관리**에 프로필 주소를 최대 10개씩 등록할 수 있습니다. **검색에 다시 표시**는 제외 기록만 제거하고 Facebook 팔로우를 취소하지 않습니다. 제외 기록 저장 실패는 실제 팔로우 성공과 구분해 알리며, 인증 만료는 남은 작업을 중지합니다. 기존 Facebook 확장 **0.1.0**을 그대로 사용하므로 검색 제외 기능 때문에 확장을 다시 설치할 필요는 없습니다.

소스는 `browser-tools/facebook-follow/`, 패키징은 `node admin-ui/scripts/package-facebook-follow-extension.mjs`입니다. 다운로드 ZIP은 고정된 소스 파일만 포함하며 로그인 없이 받을 수 없습니다. 모의 테스트와 실제 화면의 읽기 확인은 실제 팔로우 전송 성공 검증과 구분합니다.

## X

검색 결과나 저장 후보에서 프로필 **1개**를 선택하고 계정 확인을 누릅니다. 공식 API로 실행 계정 `spymedia_kor` 및 대상 ID/사용자명을 확인한 뒤, 별도 실행 버튼과 확인창에서 동의한 한 건만 전송합니다. 준비 조회도 API 이용료가 발생할 수 있습니다. '팔로워를 늘려 주는 기능'이 아니라 내 계정이 상대를 팔로우하는 기능입니다.

새 `X_FOLLOW_ENABLED` 설정은 기본 비활성입니다. 기존 인증·저장소와 `X_COST_LIMIT_ACKNOWLEDGED`도 필요합니다. 실제 운영 설정 활성화·새 권한·새 토큰·비용 변경은 사용자 승인 후에만 진행합니다. X 게시 설정을 자동 변경하지 않습니다. OAuth 1.0a 사용자 인증 또는 OAuth 2.0의 `tweet.read users.read follows.write`가 필요하며 조회 성공만으로 팔로우 권한을 검증했다고 표시하지 않습니다.

X의 규칙은 대량·공격적·무차별 팔로우를 금지하므로 선택한 목록을 자동 반복하지 않습니다. 실제 API 응답에서 완료와 승인 대기 상태를 구분하고, 전송 직전 기록 및 중복 검사를 통해 재시작·이중 클릭 후 POST를 자동 반복하지 않습니다. 원문 검색 정보는 저널에 저장하지 않습니다. 상세 설계는 `X-FOLLOW.md`를 참고하세요.

## 네이버 블로그 일반 이웃추가

SNS 계정 관리의 네이버 블로그 검색 결과 또는 저장 후보에서 **대상 선택 → 선택한 블로그 이웃추가 → 실행 블로그·광고 그룹·대상 주소 검토 → 확인한 블로그 이웃추가 시작**으로 실행합니다. 선택·검토만으로는 이웃추가하지 않습니다. 일반 이웃추가만 다루며 서로이웃 신청이나 신청 메시지는 보내지 않습니다. 기존 검색·원문 열기·블로그 원고·YouTube 링크 기능은 유지합니다.

선택한 글 주소에 블로그 ID가 명시되어 있으면 그 ID로 `https://blog.naver.com/블로그ID`를 만들고, 검토 목록에 실제 블로그 주소와 변환 이유를 표시합니다. 같은 블로그의 여러 글은 한 대상으로 합칩니다. 실행 대상은 중복을 합친 뒤 1~10개이며 자기 블로그 `spymedia`와 서비스·검색·관리 주소는 제외하거나 실행을 막습니다. 확장에는 검토한 정확한 블로그 프로필 주소만 보냅니다.

관리자의 **네이버 이웃추가 도구 0.1.0 받기**에서 별도 Chrome/Edge 확장을 내려받고 압축을 풉니다. 확장 프로그램 관리에서 개발자 모드의 **압축 해제된 확장 프로그램 로드**로 설치하며, `blog.naver.com`과 SNS 관리자 주소 및 스크립트 실행 권한을 사용자가 직접 확인·허용합니다. 기존 Instagram·Facebook 확장 권한은 변경하지 않습니다. 관리자와 네이버를 같은 브라우저 프로필에서 사용하고, 로그인한 계정의 내 블로그가 `https://blog.naver.com/spymedia`인지 확인합니다. 블로그 ID가 네이버 로그인 ID·닉네임과 같다고 가정하지 않습니다.

도구는 실행 블로그와 선택한 대상, 일반 이웃추가 폼을 확인합니다. 이웃추가 팝업에서 **이웃 → 다음 → 기존 광고 그룹 선택 → 다음** 순서를 처리하고 추가 전송은 한 번만 실행합니다. 그룹 이름은 정확히 **광고**로 고정합니다. 해당 그룹이 없으면 `group_missing`, 같은 이름의 그룹을 하나로 구분할 수 없으면 `group_ambiguous`로 중지하며 다른 그룹을 대신 선택하거나 새 그룹을 만들지 않습니다. 실행 전 `spymedia`의 기존 이웃 그룹을 확인하세요.

완료된 `added`와 이미 이웃인 `existing`만 성공 상태로 표시하고, 기존 이웃은 다시 추가하지 않습니다. 로그인 필요·다른 실행 블로그·추가 인증·보안 확인·이용 제한·불명확한 폼·결과 미확인 시 중지합니다. 결과 확인을 위한 읽기는 전송 재시도와 구분하며, 중지는 이미 완료된 이웃추가를 취소하지 않습니다.

선택 목록과 진행 상태는 페이지·확장 메모리에 최대 15분만 유지합니다. 관리자 이탈·인증 만료·선택 변경·중지·확장 재시작 후 자동 재개하지 않으며, 한 단계 응답 제한은 120초입니다. 이 기능은 이웃 전체 목록을 수집·동기화하거나 다음 검색에서 이웃을 자동 제외하지 않습니다. 계정의 비밀번호·쿠키·토큰·숨은 앱 상태를 수집하지 않고, 새 유료 서비스나 서버 작업 프로세스도 추가하지 않습니다.

네이버 공식 이웃추가 API가 아닌 사용자 브라우저의 화면 자동화입니다. 실제 로그인·화면 읽기 확인과 모의 테스트는 실제 이웃추가 성공 검증과 구분합니다. 현재 실제 이웃추가 전송·성공은 검증하지 않았으며, 설치 후 사용자가 검토하고 승인한 대상으로 확인해야 합니다. 설치를 자동으로 진행하거나 보안 확인을 우회하지 않습니다.

소스는 `browser-tools/naver-neighbor/`, 패키징은 `node admin-ui/scripts/package-naver-neighbor-extension.mjs`입니다. 고정된 소스 파일로 만든 ZIP은 `/api/admin/tools/naver-neighbor.zip`에서 관리자 로그인 후 내려받습니다.
